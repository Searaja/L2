This repository contains the data and analysis scripts for the study:

From the app to the lexicon: Neurocognitive markers of word integration in a second language

The project investigates ERP responses (e.g., N400, LPC) in a semantic decision task, including both EEG and behavioral data analyses conducted in R.

📁 repo/
├── data/
│   ├── epochs/                 # Preprocessed EEG data (.fif files, one per subject; N=21)
│   ├── epoch_amplitudes.csv    # Trial-level mean ERP amplitudes (same 21 subjects)
│   └── behavioral.csv          # Behavioral dataset (RTs, accuracy; N=24)
├── tables/
│   ├── Supplementary_Table_1.pdf   # Provided (manuscript materials)
│   ├── Supplementary_Table_2.pdf   # Provided (manuscript materials)
│   └── Supplementary_Table_3.pdf   # Generated by script.R
├── script.R                    # Main statistical analyses (GLMM / LMM) + table export
└── README.md

Participants: 24 took part and have behavioral data. EEG was usable for 21 of
them; subjects 008, 016, and 017 have no EEG files. Subject IDs are zero-padded
numeric codes (001–024).

⚙️ Requirements

EEG data

EEG data are provided as preprocessed epoch files in .fif format, compatible with MNE-Python.
Preprocessing steps (artifact rejection, ICA, filtering) are described in the manuscript.
Only preprocessed data are included; raw recordings are not distributed.

R environment

All statistical analyses were conducted in R (version 4.4.0).

Required packages:

    install.packages(c(
      "broom.mixed",
      "DHARMa",
      "dplyr",
      "emmeans",
      "flextable",
      "ggplot2",
      "glmmTMB",
      "htmltools",
      "lme4",
      "lmerTest",
      "modelsummary",
      "officer",
      "pagedown"
    ))

The supplementary-table export step calls `pagedown::chrome_print()`, which
requires a local installation of Google Chrome or Chromium.

▶️ How to reproduce the analyses

1. Download or clone this repository.
2. Open R or RStudio and set the working directory to the repository root
   (so that the `data/...` paths resolve):

       setwd("path/to/repo")

3. Run the main analysis script:

       source("script.R")

This script:

- Loads the behavioral and ERP datasets
- Fits the mixed-effects models
- Generates the results reported in the manuscript

Output written:

- `tables/Supplementary_Table_3.pdf` — regenerated in place (requires Chrome)

📊 Data description

EEG data
- 24 participants total; 21 have EEG files (missing: 008, 016, 017)
- Preprocessed epoch files (.fif), one file per subject, in `data/epochs/`
- ERP dataset: `data/epoch_amplitudes.csv`. Each row is the mean amplitude of one
  epoch at one electrode and one time window (the electrodes and windows reported
  in the manuscript).

`epoch_amplitudes.csv` columns:

| Column           | Description |
|------------------|-------------|
| `subject`        | Participant ID (001–024; 008/016/017 absent) |
| `item`           | Stimulus ID, `prime_TARGET` (e.g. `mujer_MITÃKUÑA'I`) |
| `condition_code` | 1–6, integer code for the cell below |
| `condition_label`| `remoto_no`, `reciente_no`, `español_no`, `remoto_si`, `reciente_si`, `español_si` |
| `RT`             | Reaction time for that trial, in samples at 256 Hz (divide by 256 for seconds) |
| `channel`        | Electrode: `Cz` or `Pz` |
| `window_start`   | Window onset in s: `0.3` (N400) or `0.5` (LPC) |
| `window_end`     | Window offset in s: `0.5` (N400) or `0.8` (LPC) |
| `mean_amplitude` | Mean ERP amplitude in that window (µV) |
| `relatedness`    | `0` = unrelated, `1` = related |
| `language`       | `rem` / `rec` / `esp` (recoded to L2-Remote / L2-Recent / L1 in the script) |

In `script.R` the analysis factor `word_type` is derived from `language`, and the
time window is taken from `window_start`; neither is a stored column.

Behavioral data
- `data/behavioral.csv`, all 24 participants
- Trial-level response times and accuracy

`behavioral.csv` columns:

| Column             | Description |
|--------------------|-------------|
| (leading unnamed)  | Row index from the pandas export — ignore |
| `Unnamed: 0`       | Second export index — ignore |
| `word`             | Target word (Guaraní for L2-Remote / L2-Recent, Spanish for L1) |
| `categ`            | Word type: `1` = L2-Remote, `2` = L2-Recent, `3` = L1 |
| `prime`            | Prime word (Spanish) |
| `corrAns`          | Relatedness: `right` = related, `left` = unrelated |
| `correct`          | Accuracy: `1` = correct, `0` = incorrect |
| `rt`               | Reaction time (seconds) |
| `file`             | Participant ID |
| `word_prime_merge` | Item ID (`word_prime` key) |

📈 Statistical analysis

ERP and behavioral data were analyzed with mixed-effects models:

- Accuracy: binomial GLMM (`lme4::glmer`)
- Reaction time: LMM on `log(rt)` (`lme4::lmer`)
- ERP amplitudes: Gaussian GLMM (`glmmTMB`), fitted separately per electrode × window (Cz/Pz × N400/LPC)

Fixed effects: Word Type and Relatedness and their interaction, with planned
contrasts:

- Word Type: L1 vs L2, and L2-Remote vs L2-Recent
- Relatedness: Unrelated vs Related

Random effects: by-subject and by-item.

🔍 Reproducibility notes

The repository includes preprocessed EEG data only. All analyses reported in the
manuscript can be reproduced from the provided datasets and `script.R`.

Exact numeric results depend on the manual amplitude and RT exclusion cutoffs
coded in `script.R` and on the `LOCK_MODELS` / `LOCK_EEG` flags near the top:
`TRUE` (default) uses the pre-decided random-effects structures reported in the
manuscript; `FALSE` re-runs the full `allFit` / `rePCA` / likelihood-ratio
selection pipeline. Minor differences may also occur across R and package
versions.
